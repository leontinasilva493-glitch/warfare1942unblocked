# Warfare 1942 Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a production-ready Astro game guide for `warfare1942unblocked.org` with a working CrazyGames-hosted iframe and evidence-safe SEO pages.

**Architecture:** Astro pre-renders every route to static HTML. Shared data, layout, navigation, footer, player, and content components keep metadata and factual claims consistent while page-specific Astro files own each search intent.

**Tech Stack:** Astro, TypeScript-compatible Astro components, CSS custom properties, Node's built-in test runner, static HTML validation scripts, Git and GitHub CLI.

## Global Constraints

- Preserve `design-export` and the source proposal unchanged.
- Use `https://warfare1942unblocked.org` in every production URL.
- Use `https://games.crazygames.com/en_US/warfare-1942-riz/index.html` for the required iframe.
- Do not invent codes, ratings, redemption steps, download packages, iOS support, or gameplay observations.
- Produce only static output and no server-side runtime.
- Keep the player 16:9 and keyboard accessible at all supported breakpoints.
